# Session Management Architecture\n\nA "Session" represents a component\s desire to play media. Instead of directly controlling a `<video>` tag, components register a session.\n\n## Priorities\n- `10`: Global Nav (Lowest)\n- `50`: Page Scoped (e.g., Anime Universe)\n- `100`: Fullscreen / Modals (Highest)\n\nSessions automatically expire when the component unmounts, reverting the application to the previous media state.
